# haradokei

食後の満腹度を記録し、その人の食事間隔から空腹になりそうな時刻を予測して通知する Android アプリです。

## 動作

- 食後に満腹度を 1〜5、食事量を「軽め・普通・多め」で記録
- 初回は満腹度に応じて 2〜6 時間後を予測
- 2002年4月27日生まれ・男性というプロフィールで初期値を軽く補正（年齢は端末日付から誕生日ごとに自動更新）
- 推定時刻に「もう空腹・ちょうどいい・まだ」の回答付きローカル通知を表示
- 「まだ」の場合は30分後に再確認
- アプリ内で現在の空腹度を0〜10で記録し、6以上になった時刻を空腹開始として学習
- 空腹フィードバックを食事間隔より優先し、満腹度・食事量が近い履歴を重み付きで反映
- 再起動後も未来の通知を復元
- 食事データは端末内の `SharedPreferences` のみに保存

通知時刻は医学的な空腹判定ではなく、本人の入力履歴に基づく生活支援の目安です。年齢と性別だけでは空腹時刻を正確に決められないため、プロフィール補正は控えめで、実際の空腹フィードバックを優先します。

## ビルド

JDK 17 と Android SDK 35 を用意した環境で実行します。

```sh
./gradlew assembleDebug
```

APK は `app/build/outputs/apk/debug/app-debug.apk` に生成されます。
